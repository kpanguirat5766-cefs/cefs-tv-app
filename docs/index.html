Clé d'enregistrement

Pour enregistrer vos changements, ce téléphone a besoin d'une clé GitHub. Elle se donne une seule fois et reste sur cet appareil.

  1. Ouvrez cette page GitHub.
  2. Token name : CEFS TV. Expiration : la plus longue possible.
  3. Repository access : « Only select repositories », puis cefs-tv-app.
  4. Permissions : « Contents » sur Read and write.
  5. Appuyez sur Generate token, copiez la clé (elle commence par github_pat_) et collez-la ici.
